# Approve an Action

Request approval for the current action from your mobile device via Orbiter Dev.

Usage: `/approve [description]`

This command creates an approval request that will be sent to your Orbiter Dev mobile app. You can approve or reject from your phone.

## Examples

- `/approve Deploy to production` - Creates a high-risk approval
- `/approve Run database migration` - Creates a medium-risk approval
- `/approve` - Creates a generic approval for the current action
