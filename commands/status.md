# Check Orbiter Dev Status

Check your current Orbiter Dev authentication state and pending mobile approval queue.

## Steps

1. Call `orbiter_auth_status` to verify sign-in status, user profile, and active plan.
2. Call `orbiter_list_pending_approvals` to list any approvals currently awaiting sign-off on iOS or Android.
3. Report a concise summary of authentication health, pending approvals, and setup instructions (`https://orbiterdev.ai/setup`) if pairing is needed.
